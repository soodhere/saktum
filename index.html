For boards and security teams

The seven questions boards ask about agents

Saktum answers each one with evidence, not promises.

YESCan we tell agent actions from human ones?Every call carries the agent’s own identity, its principal and its operator, in a signed receipt. receipts
YESCan agents be limited to only the tools and data they need?Mandates grant tools, action classes, rules and counterparties. Everything else is refused. --intent
YESCan we stop sensitive data leaving approved boundaries?Personal and classified data go only to the recipients the mandate names. data-not-permitted
YESCan we defend against prompt injection?Even when an agent is tricked, the mandate holds: every call is checked before it reaches the tool. demo: gift cards stopped
YESCan high-risk actions require human approval?The owner signs approval of exactly that action, once. The receipt records who approved it. agent approve
YESCan we audit what happened afterwards?Signed, hash-chained receipts, verifiable by anyone, exportable to your security tools. receipts verify · --otel
YESCan we show what agents did, and why?Each receipt records the rules checked, preferences applied and anything flagged; passports add a track record. passport --agent
Onboard: agent create + operator countersignatureReview: the track recordOffboard: agent revoke, effective at once
