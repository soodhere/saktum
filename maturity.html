Saktum MCP Maturity Model 1.0

Published 24 November 2026 · CC BY 4.0 · Levels are cumulative and defined only by evidence an independent tool can measure, so anyone can reproduce a level from the same server version.

LevelNameRequirementEvidence
L1RespondsThe server starts (or answers at its URL), completes the MCP initialisation handshake, and lists at least one tool.Saktum Check connects as an MCP client; a trust grade is produced (enough scored checks ran).
L2ConformantL1, and no failed conformance check: valid input schemas, valid tool names, and an honest answer to a call for a tool that does not exist.Scored checks in the conformance pack all pass.
L3Safe by defaultL2, and no failed security check: no hidden instructions to agents, no invisible, bidirectional or terminal-control characters, no secrets in tools or errors, no stack traces or source paths in errors; local HTTP servers refuse foreign web origins.Scored checks in the security pack all pass.
L4Agent-readyL3, and agent readiness A: tools declare danger annotations, have usable descriptions, and keep context cost reasonable.Agent readiness score of 90 or more (annotations 30%, descriptions 40%, context cost 30%, with partial credit).
L5AssuredL4, and a verifiable supply chain: the package publishes provenance (for npm, a provenance attestation) and runs no install scripts.Registry metadata for the exact version checked.

Measuring a level

Assess a specific version without credentials and without calling tools; record the tool fingerprint, since a level applies only while the tools match it; servers that need configuration or credentials to start are not assessed rather than given a low level.

Relation to other measures

Assurance levels describe who ran the assessment (L1 self-tested, L2 independently run, L3 certified); maturity describes what the evidence shows. OWASP MCP Top 10: L2 and L3 evidence covers parts of MCP01, MCP03, MCP05, MCP06 and MCP07, and L5 part of MCP04. Trust and agent-readiness grades are finer measures from the same checks.

Used in the State of MCP Trust census. Measure your own server: npx saktum check -- npx -y your-package. Changes are versioned; proposals welcome at github.com/soodhere/saktum-index.
